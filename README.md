# 🐉 ESP-Hunter
### *Многофункциональный хакерский инструмент на базе ESP32-S3*

> **«Охота началась.»**  
> ESP-Hunter — это портативная кибер-платформа, объединяющая в себе десятки инструментов для пентеста, радиоигры, автоматизации и кибербезопасности. Всё, что нужно хакеру, умещается в кармане.

---

## 🔥 Ключевые возможности

| Модуль | Функции |
|--------|---------|
| **📺 Remote Display** | Трансляция экрана устройства в ПК-приложение в реальном времени, удалённое управление D-Pad |
| **⚡ One-Click OTA** | Автоматическое обновление прошивки напрямую из GitHub-релизов без сложной настройки |
| **📻 Sub-GHz (CC1101)** | Приём и передача радиосигналов на 315 / 433 / 868 МГц, захват, сохранение на SD, эмуляция выбранных пакетов |
| **📡 RFID/NFC** | Чтение, запись, стирание и эмуляция меток Mifare Classic через модуль PN532 (I2C) |
| **✴️ IR (Инфракрасный)** | TV-B-GONE (98+ кодов) для выключения телевизоров и кондиционеров, приём и передача любых ИК-сигналов |
| **⌨️ BadUSB (USB HID)** | Эмуляция клавиатуры для выполнения скриптов: открытие блокнота, терминала, выключение ПК, смена обоев, отключение иконок, дамп Wi-Fi паролей |
| **🚨 Evil Portal** | Создание фальшивой точки доступа с поддельной страницей Google Auth; захват учётных данных и сохранение на SD |
| **📶 Wi-Fi & BLE** | Сканирование сетей, Beacon Spam, Deauth-атаки, Wardriving с записью в CSV; BLE-сканер и BLE Spam (эмуляция AirPods) |
| **🖥 Serial Manager** | Встроенный ПК-клиент в стиле qFlipper для мониторинга порта и удалённого управления |
| **🎮 Игры** | Классический Pong — сражение с ИИ на 128x128 TFT |

---

## 🧩 Аппаратная платформа

- **Микроконтроллер:** ESP32-S3 (Dual-Core LX7, 240 МГц)
- **Память:** 16 МБ Flash + 8 МБ PSRAM
- **Дисплей:** ST7735 128x128 TFT (SPI)
- **Интерфейсы:** USB CDC, SPI, I2C, MicroSD, Wi-Fi, Bluetooth LE
- **Периферия:** PN532 (RFID), IR-приёмник/передатчик, CC1101 (Sub-GHz), кнопки D-Pad (UP/DOWN/OK/ESC)

---

## 🎯 Основные идеи

- **Модульность:** Все функции разделены на логические меню, легко переключаются с помощью D-Pad.
- **Автономность:** Работает от USB или внешнего питания, не требует ПК для базовых операций.
- **Расширяемость:** Возможность добавлять новые модули через прошивку.
- **Безопасность:** Все данные (логи, захваченные сигналы, пароли) сохраняются на MicroSD.

- MicroSD-карта (опционально)
- Кабель USB‑C для питания и связи

---

## 🛠 Установка и сборка

1. **Загрузите прошивку** из [Releases](https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/ВАШ_РЕПОЗИТОРИЙ/releases) через esptool или OTA.
2. **Подключите периферию:** PN532, CC1101, ИК-диоды по схеме (распиновка указана в коде).
3. **Вставьте SD-карту** для хранения конфигов и логов.
4. **Подключите по USB** — устройство готово к использованию.
