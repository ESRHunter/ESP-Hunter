ESP-Hunter

Открытая прошивка и ПК-менеджер для управления устройствами, диагностики, работы с беспроводными интерфейсами и автоматизации.

Скачать приложение (.exe) Скачать прошивку (.bin) Подробнее

Remote Display

Трансляция экрана устройства в ПК-приложение в реальном времени и удаленная эмуляция нажатий кнопок D-Pad.

One-Click OTA

Автоматическое обновление прошивки ESP32-S3 напрямую из свежих релизов GitHub без сложной настройки.

Sub-GHz CC1101 Hub

Анализ и приём радиосигналов на частотах 315 / 433 / 868 МГц с возможностью записи и воспроизведения. Скоро будет добавлен.

Serial Manager

Встроенный ПК-клиент в стиле qFlipper с удобным монитором порта и логами выполнения в реальном времени.

RFID

Чтение, запись, стирание и эмуляция RFID меток благодаря модулю PN532.

IR RX/TX

TV-B-GONE из 98 разных сигналов, прием и отправление любых ИК сигналов.

BadUSB HID Attacks

Автоматизированная эмуляция USB-клавиатуры для выполнения скриптов (BadUSB). Отключение ПК, смена обоев, дамп Wi-Fi паролей и другие пентест-сценарии.

Evil Portal

Создание фальшивой точки доступа (AP) с поддельной страницей авторизации. Захват учётных данных (Google Auth) и тестирование фишинга в локальной сети.

Wi-Fi & BLE

Сканирование эфира и Wardriving. Запуск Deauth-атак (отключение клиентов), Beacon Spam и BLE Spam (эмуляция AirPods) для оценки уязвимостей.

Hardware Specs (v1.0)

Микроконтроллер ESP32-S3 (Dual-Core LX7)
Дисплей ST7735 128x128 TFT
Память 16 MB Flash / 8 MB PSRAM
Интерфейсы USB CDC, SPI, MicroSD, I2C
