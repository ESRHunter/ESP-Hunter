Desktop Flasher Hub // ESP32-S3

Автономный локальный прошивальщик с автоматической загрузкой прошивки из открытых релизов GitHub.

Центр Управления Прошивкой

Для 100% стабильной прошивки плат с нативным USB или чипами CH343 используется локальное Python-приложение. Оно автоматически обращается к GitHub API, скачивает актуальный `.bin` файл и прошивает вашу плату через `esptool`.

📦 Релизы на GitHub

⚡ Порядок Подключения Устройства:

  1. Подключите плату ESP32-S3 по USB-C кабелю.
  2. Зажмите физическую кнопку BOOT (или 0).
  3. Нажмите и отпустите кнопку RESET (RST / EN).
  4. Отпустите кнопку BOOT.
  5. Запустите `ESP-Hunter_flasher.exe`, выберите ваш COM-порт и нажмите DOWNLOAD & FLASH LATEST.
